# CS_370_Artifact

## Reflection

For this project, I was given a foundational Python starter code template within a Jupyter Notebook that set up the maze environment, including the basic layout of the walls, the treasure placement, and the structural rules for how the pirate agent could move around. My job was to create the actual brains of the operation by building a deep Q-learning reinforcement learning model. I wrote the code to construct the artificial neural network using Keras and TensorFlow, implemented the exploration and exploitation strategy using an epsilon-greedy algorithm, and coded the training loop that processed game states, calculated immediate rewards, and updated the Q-values. Through the code I created, the pirate agent learned how to autonomously navigate the maze, avoid dead ends, and find the optimal path to the treasure in fewer steps over time.

This course showed me that computer scientists do not just write static code, but rather design intelligent systems and algorithms that solve complex, unpredictable problems, which matters because it allows us to automate difficult tasks and make technology truly adaptive to human needs. As a computer scientist, I now approach a problem by breaking it down into an environment of distinct states, actions, and constraints, looking for ways an algorithmic agent can optimize its choices through continuous testing and feedback loops. When developing these powerful systems, my ethical responsibilities to the end user and the organization include protecting their personal privacy through practices like data minimization and local edge computing, while ensuring the software encourages human autonomy instead of causing tech dependence. Moreover, my responsibility is to write transparent, well-tested, and secure code that aligns with regulatory frameworks like GDPR, ensuring the artificial intelligence models we deploy are both reliable and socially responsible.
